GraphScribeTurn Blueprints into readable docs and AI-ready graphs

An Unreal Engine editor plugin that exports Blueprint graphs into Markdown, Graphify, Mermaid, and JSON formats. So your gameplay logic is readable outside the editor, and AI can actually understand it.

Get Started
View on Fab

  • One-Click Export

    Export a single Blueprint, a whole folder, or just the nodes you selected. No config, no scripting. Open the editor and start in under a minute.

  • Readable Markdown

    Every Blueprint becomes clean, human-readable Markdown that contains variables with defaults, functions, graphs, delegates, class references, and widget trees. Perfect for docs, pull requests, and code review.

  • Graphify for AI

    A project-wide knowledge graph with stable links between Blueprints and functions. AI agents can answer "who calls this function?" impossible with .uasset binaries.

  • Mermaid Diagrams

    Visual flowcharts of your graphs and widget hierarchies that render anywhere. GitHub, GitLab, Notion, or your docs site.

  • Full JSON Dump

    A complete structured dump of nodes, pins, edges, variables, and diagnostics for custom tooling and scripts.

  • PR-Ready Diffs

    "Changed a binary file" becomes "added Add Score (Amount = 25)". Commit exports next to your code and review Blueprint changes like code.
