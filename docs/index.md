features:
  - title: One-Click Export
    details: Export a single Blueprint, a whole folder, or just the nodes you selected. No config, no scripting. Open the editor and start in under a minute.
  - title: Readable Markdown
    details: Every Blueprint becomes clean, human-readable Markdown that contains variables with defaults, functions, graphs, delegates, class references, and widget trees. Perfect for docs, pull requests, and code review.
  - title: Graphify for AI
    details: A project-wide knowledge graph with stable links between Blueprints and functions. AI agents can answer "who calls this function?" impossible with .uasset binaries.
  - title: Mermaid Diagrams
    details: Visual flowcharts of your graphs and widget hierarchies that render anywhere. GitHub, GitLab, Notion, or your docs site.
  - title: Full JSON Dump
    details: A complete structured dump of nodes, pins, edges, variables, and diagnostics for custom tooling and scripts.
  - title: PR-Ready Diffs
    details: '"Changed a binary file" becomes "added Add Score (Amount = 25)". Commit exports next to your code and review Blueprint changes like code.'
